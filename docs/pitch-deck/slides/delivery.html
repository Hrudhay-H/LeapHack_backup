08 / 14

Three audiences, one report. A farmer with a smartphone signs in and sees the dashboard and PDF. A farmer with a keypad phone gets an SMS and collects the report through a village operator. The same PDF is served to both, so nothing is generated twice. The assisted flow, in order: the operator finds the farmer by ID and sees only a masked phone number; the system sends a six-digit code to the farmer’s registered phone; the farmer enters it. The code is hashed, single-use, expires in five minutes and locks after three wrong tries. The operator then receives a token for that one report, valid five minutes, and every view and download is written to an audit log. Say the caveat: a one-time code proves control of the registered phone, not identity. A real deployment needs a documented FPO-verified fallback. The SMS gateway here is a mock; real Indian SMS needs a DLT-registered sender and approved templates, and Kannada must be sent as Unicode.

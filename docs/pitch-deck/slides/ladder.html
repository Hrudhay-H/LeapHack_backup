This is the slide that keeps us honest. Each row is a different kind of claim. Row 1 shows the software works: it localises damage we deliberately drew in. It cannot show it finds pests. Row 2 is real imagery with labels that are proxies: index-derived masks, subplot severity, or close-range photos. Useful for seeing which signal is dependable; not an accuracy figure for pests. Row 3 is what a real claim needs: scouts walking to hotspots and recording what they find. We have none yet. We built the loop that collects it, and we say so rather than quoting a number. If a judge asks what the accuracy is: there is no honest pest-detection accuracy yet, and here is the plan to get one.
